01 — The Verdict

This model is better in almost every way

The Coin + Tournament Model is Genuinely Smarter

You've solved your biggest problem — gambling regulation — without losing any of the financial upside. Instead of players betting against each other (which triggers gambling laws in most jurisdictions), players buy coins to enter tournaments and earn revenue share based on performance. This is the Fortnite/League of Legends model applied to a skill sport. It's legally categorized as a skill competition with revenue sharing, not gambling. The prize pool being funded by ad revenue, coin sales, and subscriptions — not player-to-player wagers — is the key distinction.

To your direct question: Yes, if you get legal docs, geo-block restricted regions, verify age at first open, and maintain withdrawal limits — with this coin model instead of direct 1v1 money gambling — you are in a dramatically better position. You're not "good to go" without proper legal counsel reviewing your specific structure, but you've removed the single hardest problem (gambling licensing) from your path. The tournament revenue-share model has worked globally for companies like ESL, DraftKings (in skill mode), and numerous mobile esports platforms.

v1.0 — Direct 1v1 Money

Real-Money Betting Model

  • Gambling license required in most countries
  • Banned outright in 6+ US states
  • Apple/Google severely restrict real-money wagering
  • Player trust at risk from every bad actor
  • Regulatory cost: $100k–$500k+ upfront
  • Chargeback liability on every disputed match
  • Money laundering surface area is enormous
v2.0 — Coin Tournament Model

Skill Competition + Revenue Share

  • No gambling license required (entertainment/gaming classification)
  • Legal in most US states as a skill competition
  • App Store / Play Store compliant
  • Platform takes house cut from coin sales, not player wagers
  • Regulatory cost: $10k–$30k (standard business legal)
  • Disputes handled by tournament rules, not finance department
  • Crypto payouts limited to top performers (not general wallet)

05 — Tech Stack

The Architecture Blueprint

Rendering

3D Graphics Engine

Three.js with React Three Fiber for the 3D pool table. PBR ball materials (polished resin shaders), real-time felt texture, dynamic cue stick animation, chalk dust particle system on collision. Runs in a WebGL canvas embedded in the React Native app via expo-gl or a WebView bridge.
Three.js r160+ React Three Fiber @react-three/drei GLSL Custom Shaders expo-gl
Physics

Ball Physics Engine

Custom billiard physics layer on top of a rigid-body engine. True rolling friction, side-spin/english, masse shot simulation, accurate cushion rebound with throw, pocket jaw detection. CRITICAL: physics runs server-side. Clients send aim angle + power + spin input only. Server resolves shot, streams ball positions back as delta updates at 60fps. This prevents cheating entirely.
Custom Pool Physics Box2D WASM Server-Side Authority Delta State Sync
Mobile App

React Native + Expo

Single codebase for iOS and Android. Expo SDK for OTA updates, push notifications, and in-app purchases. Reanimated 3 for buttery UI animations outside the game canvas. Zustand for client state. RevenueCat as the IAP middleware handling both Apple and Google receipt validation with one API.
React Native Expo SDK 52+ Reanimated 3 RevenueCat IAP Zustand
Realtime

Multiplayer Game Server

Colyseus is purpose-built for real-time multiplayer game rooms — handles room lifecycle, player state sync, reconnection, and spectators natively. Node.js host. Each match gets its own room instance. Redis pub/sub for cross-server tournament bracket coordination. WebSocket connections proxied through Cloudflare for DDoS protection.
Colyseus Node.js 20+ WebSockets Redis Pub/Sub Cloudflare Proxy
Data

Database Layer

PostgreSQL for everything persistent: player profiles, wallets, match history, tournaments, transactions, KYC status. Redis sorted sets for live leaderboards with O(log N) rank queries — critical for 100k+ concurrent players. TimescaleDB extension for time-series analytics. Prisma ORM for type-safe queries.
PostgreSQL 16 Redis 7 TimescaleDB Prisma ORM
Payments

Coin & Crypto Payments

RevenueCat handles all IAP (coin packs via App Store / Play Store). Stripe for web-based coin purchases and premium subscriptions. Coinbase Commerce or Circle for USDC prize payouts to winners. Plaid for optional bank account linking for larger withdrawals. All crypto payouts are outbound only (platform paying winners) — no crypto deposits from users, keeping AML surface area minimal.
RevenueCat Stripe Coinbase Commerce Circle (USDC) Plaid
Compliance

KYC / Age Verification

Age verification at first app open (mandatory, not optional). Stripe Identity for KYC at the thresholds you defined. Onfido as backup provider. Geo-blocking via Cloudflare Workers + IP database to prevent access from restricted regions automatically. Comply Advantage for sanctions screening on any user receiving crypto prize payouts above $200.
Stripe Identity Onfido Cloudflare Geo-block Comply Advantage
Infrastructure

Cloud & DevOps

Multi-region game servers (US-East, EU-West, Asia-Pacific) for low latency. AWS EC2 for game servers, S3 for match replays and assets. Railway for easy game server horizontal scaling. Cloudflare CDN for static assets and WebSocket proxying. Docker + GitHub Actions CI/CD. Grafana + Prometheus for game server monitoring.
AWS EC2 / S3 Railway Cloudflare Docker Grafana GitHub Actions

07 — Legal & Compliance

What Makes This Safe to Launch

✓ You've Already Covered

Your Good Decisions

  • Coins not redeemable for cash (not gambling)
  • Prize pool from platform revenue, not player wagers
  • KYC at tiered thresholds ($100/$500/$1k/$4k)
  • Age verification at first open (before any play)
  • Withdrawal limits in place
  • Rules displayed before every tournament entry
  • No ads-to-coins path (no manipulation)
  • Withdrawal limits mirror your deposit limits
◆ Still Need to Add

Important Additions

  • Responsible gaming: deposit limits user can set themselves
  • Self-exclusion (24hr / 7-day / permanent options)
  • Cooling-off period after large spend
  • Display total spend in the past 30 days prominently
  • Crypto prize payouts need OFAC sanctions screening
  • Tax reporting: 1099 for US players earning $600+/year
  • GDPR compliant data handling for EU users
  • Separate escrow for prize pool funds
  • Dispute resolution process documented in ToS
! Before Launch — Non-Negotiable

Legal Prerequisites

  • Hire a real-money gaming attorney to review the full model
  • Get legal opinion on skill competition classification per country
  • Geo-block: WA, MT, ND, SD (US) + any country requiring gambling license for crypto prizes
  • Business entity in gaming-friendly jurisdiction (Delaware LLC, UK Ltd, Malta for EU)
  • Privacy Policy, Terms of Service, and Contest Rules reviewed by counsel
  • App Store / Play Store pre-submission review for real-prize competitions
  • Open segregated bank account for prize pool funds
◆ Anti-Cheat & Trust

Platform Integrity

  • Server-side physics — clients send only input, never state
  • Input timestamp validation (prevents replay attacks)
  • Device fingerprinting for multi-account detection
  • Collusion detection (same IP, coordinated throw patterns)
  • VPN / proxy detection with soft warning before block
  • Human referee appeal process for major tournament disputes
  • AI anomaly detection on play patterns (unusual win rates, timing)
  • Rate limiting on tournament entries per account
08 — Build Roadmap

The Execution Path

Phase 0 — Weeks 1–6 — Before Any Code

Legal & Business Foundation

Hire gaming attorney. Incorporate business entity. Get legal opinion on coin-tournament-crypto-prize model in target launch markets. Draft ToS, Privacy Policy, Contest Rules. Open operating account + separate prize pool escrow account. Get Google Play and Apple developer accounts, submit category intent for real-prize competitions. Set up entity for crypto prize disbursement (Coinbase Commerce business account).

Phase 1 — Months 2–4 — Core Game

Physics Engine + 1v1 Free Play

Build the pool physics engine first — this is the product. Get 8-ball perfect. Nail server-side physics authority architecture. Build the Colyseus match room system. Build 3D renderer with Three.js. Launch internal testing. Add spectator mode and match replay. Obsessively fix physics desync, network lag compensation, and edge cases before a single coin system exists.

Phase 2 — Months 4–6 — Coins & Cosmetics

Economy, Store, Customization

Build coin economy. Integrate RevenueCat for IAP coin packs. Build cosmetics store (cue skins, table felts, ball sets). Implement age verification at first open. Build user wallet and transaction history. Launch premium subscription via Stripe. Begin closed beta with invite-only registration. Iterate on coin balance and spend rates based on real data.

Phase 3 — Months 6–9 — Tournament Engine

Brackets, Leaderboards, Crypto Prizes

Build full tournament bracket system (single elimination, 2048/8192/32768 player brackets). Build leaderboard with full tiebreaker logic in Redis sorted sets. Implement multiple rulesets (8-ball, 9-ball, 10-ball, one-pocket). Build mandatory rule disclosure modal. Wire up KYC triggers at your defined thresholds. Integrate Circle/Coinbase for USDC prize payouts. Launch first public paid tournament as beta event.

Phase 4 — Months 9–12 — Scale & Polish

Full Public Launch + Growth Engine

Launch all tournament tiers (Daily × 20, Weekly × 14, Monthly × 2–4). Activate geo-blocking for restricted regions. Launch referral program. Seasonal content updates (new cosmetics). Community cue creator marketplace. First sponsored major tournament. Expand to second language market. Begin work on snooker and 3-ball variants.

Phase 5 — Year 2+ — Ecosystem

Esports, Clans, Live Streaming Integration

Clan/team competitions. Twitch/YouTube live streaming integration with viewer interaction. Pro player partnerships and verified accounts. Annual CueMaster Championship (flagship event, large prize pool, headline sponsor). Native web app for desktop play. International expansion to UK, EU, Southeast Asia markets with proper licensing per region.
